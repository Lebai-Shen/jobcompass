# JobCompass 求职指南针

面向在校求职者的岗位成长路径工具。用户输入目标岗位，系统输出岗位要求拆解、分阶段学习路径、真实面经与课程推荐，所有内容保留来源与可信度标注。

本项目同时承担两个目标：作为 AI 产品经理方向的求职作品集，以及作为一个真实可用的产品验证需求。

## 项目能力覆盖

产品方向包括用户调研、竞品分析、产品定位、需求文档、用户故事、原型设计与指标设计。

AI 方向包括提示词设计、检索增强、结构化输出、模型接入与成本控制。

工程方向包括前后端开发、数据库设计、接口设计与用 AI 协作编码。

## 运行方式

启动后端，会自动建库、写入初始内容、提供接口并托管前端页面：

```
python backend/run.py
```

浏览器访问 http://127.0.0.1:8000

也可以直接双击 `demo/jobcompass-prototype.html`。这种方式使用页面内置数据，不依赖后端。

## 模型配置

在 backend 目录下创建 `.env` 文件，写入：

```
DEEPSEEK_API_KEY=你的密钥
```

未配置密钥时，产品会使用数据库中的已有内容，功能不受影响。
