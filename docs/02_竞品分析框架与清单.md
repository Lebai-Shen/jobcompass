# 竞品分析框架与清单（初版）

> 这一份先给你 **方法论 + 竞品清单 + 分析维度**，让你知道「竞品分析到底在分析什么」。相关事实我会逐步用检索核实、补进表格。

---

## 一、为什么做竞品分析（给新手）

竞品分析的目的不是「抄作业」，而是回答三个问题：

1. **这个赛道别人已经做到哪了？** 有没有人已经解决了你要解决的问题？
2. **我和别人差在哪、凭什么用户选我？** 找到差异化机会。
3. **哪些坑我能提前避开？** 别人踩过的坑、被骂的功能，就是我的前车之鉴。

---

## 二、竞品分类（先分清"他们是谁"）

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| **直接竞品** | 解决同样问题的同类产品 | 求职类 AI 助手、面试题库 App |
| **间接竞品** | 能解决部分诉求，但不是主打 | 牛客网、小红书、B站、知乎、脉脉 |
| **替代方案** | 用户不用你也能凑合 | 直接问 ChatGPT / DeepSeek、用搜索引擎 |
| **配套/数据源** | 提供内容或岗位数据的平台 | Boss直聘、拉勾、智联、牛客、小红书 |

---

## 三、分析维度（每个竞品都看这 7 项）

1. **定位**：一句话它在卖什么、给谁
2. **目标用户**：学生 / 在职 / 校招 / 社招
3. **核心功能**：它解决了哪几个关键场景
4. **内容 / 数据**：内容来自哪里、怎么生产、质量如何
5. **AI / 智能化程度**：有没有用 AI？是套壳还是真本事（RAG、Agent）？
6. **体验**：上手难度、有没有「路径感」、交互是否友好
7. **商业模式**：免费 / 付费 / 广告 / B 端 / 导流

---

## 四、初步竞品清单（待逐个核实）

### 直接竞品 / 替代

- **直接把问题丢给 ChatGPT / DeepSeek**：最直接的「替代方案」，也是我最需要差异化的地方
- **求职 / 面试类 AI 助手**（市场上出现的一些")：待调研有哪些、做到什么程度

### 间接竞品（内容社区 / 教程）

- **牛客网**：面试题、面经、求职社区，最接近我
- **小红书**：大量真实求职经验帖 + 面经，但需用户自己搜
- **B站**：教程/课程，但没有「串联成路径」的能力
- **知乎 / 脉脉 / 一亩三分地**：经验、薪资、行业讨论

### 配套 / 数据源

- **Boss直聘 / 拉勾 / 智联**：岗位 JD（说明岗位要什么，但数据含个人信息，要谨慎）
- **面经 / 题库类**：各大厂面经汇总（网络公开内容）

---

## 五、每个竞品我都要回答的问题（用户研究工具）

针对每个竞品，回答这 6 句：

1. 用户为什么用他？（动机）
2. 用户用他解决了什么？没解决什么？（缺口）
3. 用户在什么时候用？（场景）
4. 他最让用户头疼的地方是？（痛点）
5. 用户会为了什么离开他 / 不长期用？（流失点）
6. 如果我能只做一件他做不到的事，那是什么？（机会）

---

## 六、输出模板（最终竞品分析文档）

```
1. 竞品背景（一句话定位 + 目标用户 + 简介）
2. 功能对比表（我们 vs 竞品，按「核心场景」逐项对比）
3. 用户评价与痛点（摘录代表性用户反馈）
4. 差异化机会（我们能做、竞品做不好的 1–2 点）
5. 风险与借鉴（什么不该学、什么必须借鉴）
6. 结论：我们 THE 到底是什么（一句话差异化定位）
```
