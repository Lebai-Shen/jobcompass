## 0. 一句话结论（先看这个）

这个赛道**已经很卷**：面经检索、简历优化、模拟面试、AI 实时答题，一抓一大把，且基本都聚焦在「面试 / 简历」阶段。

但有一个明显的**空白点**：**「根据目标岗位，自动生成一条可执行的学习成长路径 + 匹配教程 + 串联面经考点」——这个从"我想做PM但不知道从哪学起"到"我知道每一步该干嘛"的入口，几乎没人做。** 而且**没人专门深耕「产品经理 / AI 产品经理」这类"要懂一点技术、但又不是纯技术"的复合岗**。

👉 这就是我们的差异化机会：**做「目标岗位的成长路径导航」，而不是又一个「模拟面试 App」。**

## 2. 核心竞品逐个分析

### 2.1 牛客网（最老牌、最贴近）

- **定位**：大学生求职一站式社区（实习/校招 + 题库 + 面经 + 内推）
- **目标用户**：应届生、在校生
- **核心能力**：名企笔面试题库、面经社区、校招信息、内容 UGC
- **AI 程度**：低（传统社区 + 题库，AI 化在追赶）
- **优势**：内容量大、用户多、真题全
- **劣势**：**信息靠用户自己搜、不成体系**；没有"我该走什么路径"的引导；找 PM 面经要自己翻
- **对我们的启示**：别做"又一个面经社区"，要做的正是它没做的"路径串联 + 个性化"

### 2.2 Offer蛙 / 面面通 / 面试狗（AI 面试答题类）

- **定位**：AI 实时辅助面试，语音转文字，1 秒出答案 / 逐字稿 / 题库
- **目标用户**：临面试、急需应付的求职者
- **核心能力**：实时语音分析、定制化答案库、题库
- **AI 程度**：高（但偏"答题/提词"，不是"学习路径"）
- **优势**：解决"临阵慌乱"，见效快
- **劣势**：**只解决"面试那一刻"，不解决"长期怎么学"**；同质化严重、容易被打上"作弊/提词"标签 ⚠️（合规与口碑风险）
- **对我们的启示**：这类产品解决的是"最后一公里"，我们要做的是"从 0 到 1 的第一公里"，可错位共存

### 2.3 FaceTomato（面柿，开源）⭐ 最接近我们

- **定位**：面向技术岗的 AI 求职准备平台，简历解析 + JD 匹配 + 面经检索 + 模拟面试 + 复盘
- **目标用户**：技术岗求职者（算法/开发为主，也覆盖产品经理等）
- **核心能力**：面经库检索、模拟面试（RAG + Agent + 语音）、复盘报告
- **AI 程度**：高（Agent + RAG）
- **优势**：技术先进、全流程、开源可参考
- **劣势**：**主链路是"面试演练"，不是"学习路径"**；主打技术岗；学习/入门环节弱
- **对我们的启示**：**技术方案可以借鉴**（RAG + Agent + 面经结构化 + 复盘），但要**避开它的定位**，主打"路径规划 + 入门成长"，并深耕"产品经理/AI 产品经理"垂直岗

### 2.4 prisma-ai（pinkprisma，开源）⭐ 也很像我们

- **定位**：求职 AI co-pilot，优化项目/简历、匹配工作、面试准备 + 万篇面经数据库（结构化 + 思维导图 + Anki）
- **目标用户**：需通过技术面试的求职者
- **核心能力**：面经数据库、AI 结构化补全、标准答案、思维导图、Anki 卡片、AI 对话答疑
- **AI 程度**：高（题库 + AI 对话 + 复习工具）
- **优势**：数据量大、知识库做得好、AI 答疑
- **劣势**：**偏"题库 + 记忆"**（背题导向），**不是"路径生成"**；主打技术岗；无"先学什么/怎么学"的分阶段成长指引
- **对我们的启示**：**它的"面经结构化 + 标注来源"手法很值得学**（正好对应你的"整理面经库"）；但我们要加上**动态、按岗位生成的学习路径**

### 2.5 职小灶 / 产品经理面典（分岗位题库）

- **定位**：分行业/分岗位面试真题 + 模拟面试
- **目标用户**：各岗位应届生 / 转行者
- **核心能力**：岗位定制题库、模拟面试（投 PM 就练 PM 题）
- **AI 程度**：中
- **优势**：岗位区分清楚，PM 有专门题库
- **劣势**：**纯题库，无路径、无教程推荐**；只是"刷题"
- **对我们的启示**：说明"产品经理岗"有真实需求，但缺"体系化成长"；我们可以在"题库"之上加"路径"

## 3. 用户评价与痛点（公开信息提炼）

直接引用「为什么做」类产品创始人的说法，更能说明痛点：

- prisma 开发者：「**受够了网上杂乱的面经**……收集上万篇真实面经，用 AI 结构化整理成体系化知识库。」
- FaceTomato 开发者：「针对**简历优化、面经复习及模拟面试等流程割裂**的痛点……打造全流程解决方案。」

👉 这说明：**"信息杂、流程割裂、不成体系"是公认痛点。** 但他们都把答案落在"整理面经/模拟面试"，**没有落在"帮你规划一条从 0 开始的路"**。

## 4. 差异化机会（我们 vs 他们）

| | 他们 | 我们 |
| --- | --- | --- |
| 切入阶段 | 面试 / 简历阶段（最后一公里） | **入门阶段（第一公里）** |
| 核心产物 | 题库、模拟面试、简历 | **按岗位生成的学习成长路径 + 教程** |
| 面向岗位 | 技术岗为主 | **产品经理 / AI 产品经理等复合岗** |
| 用户路径 | 用户主动找题 | **系统告诉你"先学什么、再学什么"** |
| 解决 | "怎么应付面试" | **"我到底该怎么入门"** |

**我们的差异化一句话**：不是"帮你背题、帮你面试"，而是**帮你从"想做这个岗位但完全不知道从哪开始"一步步导航到"我知道每一步该干什么、去哪个课学、面试考什么、练到什么程度"。**

## 5. 风险与借鉴

### 要借鉴的（别人做对了的）

1. **面经结构化处理 + 标注来源**（prisma / FaceTomato 的做法，支撑你的"面经库"）
2. **RAG + Agent 工作流**（检索真实面经再回答，降低幻觉）
3. **模拟面试 + 复盘**（后期作为扩展功能，很刚需）
4. **垂直岗位深耕**（"产品经理岗"有专门需求，比做"通用全岗位"更易建立口碑 + 更好切入）

### 要避开的（别人的坑）

1. **AI 提词器 / 实时答题**：有"作弊"口碑与合规风险，别碰
2. **纯题库 / 纯背题**：可做补充，但不能是主定位，否则沦为红海
3. **爬虫全量抓取**：版权与反爬风险高，MVP 先用人工 + 公开 + AI 数据
4. **一次性功能**：要设计"留存"（进度打勾、路径更新、面经收藏），否则用户用完即走 ℹ️（这是本产品能否"可用"的关键）

---

## 6. 结论：把产品定位重新校准

> **我们不是"求职面试 App"，而是"目标岗位的成长路径导航"。**
>
> MVP 先做透一件事：**输入「产品经理 / AI 产品经理」→ 生成可执行的分阶段学习路径 + 匹配教程 + 串联面经考点。**
>
> 先深耕"产品经理 / AI 产品经理"这个垂直岗位，再逐步扩展。
