# 用户故事

本文档把产品需求拆成可开发、可验收的条目。每条包含角色、目标、价值与验收标准。

角色定义：

游客指未登录用户。用户指已登录用户。会员指已订阅用户。

## 史诗一：岗位输入与路径生成

### US-1.1 输入目标岗位

作为游客，我希望在首页直接输入想找的岗位，以便马上知道自己该往哪个方向准备。

验收标准：

- 首页首屏可见岗位输入框，无需滚动即可看到。
- 输入框支持自由输入，也可以从热门岗位中直接选择。
- 空输入时点击生成，给出提示，不发起请求。
- 输入内容包含"AI"或"人工智能"时，默认匹配 AI 产品经理方向。

### US-1.2 补充个人背景

作为游客，我希望勾选自己的学历、年级与经验情况，以便生成的内容更贴近我的起点。

验收标准：

- 背景选项支持多选。
- 默认选中"大四 / 应届"与"零产品经验"。
- 提供"更多"入口，展开后显示额外选项。
- 勾选状态在生成时随请求一起提交。

### US-1.3 生成成长路径

作为游客，我希望点击一次就能生成完整的成长路径，以便快速判断这个产品对我有没有用。

验收标准：

- 点击后进入生成中状态，逐条展示当前进度。
- 生成耗时超过预期时，页面保持可读，不出现空白。
- 生成失败时给出说明并回退到已有内容，不出现报错页面。
- 生成成功后进入成长路径页，默认展示岗位要求板块。

### US-1.4 生成结果入库与复用

作为产品维护者，我希望同一个岗位的生成结果被保存并复用，以便控制调用成本。

验收标准：

- 同一岗位名第二次请求时直接使用已保存结果。
- 已保存结果标记来源为 AI 生成。
- 结果按岗位拆分为技能、达标标准、学习阶段、面经与课程分别存储。

## 史诗二：学习路径与进度

### US-2.1 查看岗位要求

作为游客，我希望看到这个岗位的必备技能、加分技能与达标标准，以便判断自己现在的差距。

验收标准：

- 必备技能与加分技能分区展示。
- 达标标准以可验证的描述呈现，不使用空泛表述。
- 内容区域在移动端可正常阅读。

### US-2.2 查看分阶段学习路径

作为游客，我希望看到按时间排列的学习阶段，以便知道先做什么、后做什么。

验收标准：

- 每个阶段包含标题、时长、任务清单、交付物与验收标准。
- 阶段按顺序编号。
- 每个阶段可关联一个或多个学习资源链接。

### US-2.3 标记任务完成

作为用户，我希望勾选已完成的任务，以便看到自己的推进情况。

验收标准：

- 任务支持勾选与取消勾选。
- 已完成任务呈现划线状态。
- 页面顶部显示"已完成 X / Y"与完成百分比。
- 勾选状态随学习计划一起保存。

## 史诗三：面经题库

### US-3.1 查看岗位高频面经

作为游客，我希望在成长路径页看到这个岗位的高频面经，以便了解面试会问什么。

验收标准：

- 面经条目展示题目、标签、来源与可信度。
- 游客可查看固定数量的面经条目。
- 超出部分展示锁定状态与解锁入口。

### US-3.2 展开答题思路

作为游客，我希望点开一道题就能看到答题思路，以便知道该从哪里作答。

验收标准：

- 每条面经提供展开与收起操作。
- 展开后显示答题思路文本。
- 收起后恢复列表形态。

### US-3.3 按条件筛选面经

作为用户，我希望在面经题库页按岗位、公司、年份筛选，以便找到与自己目标接近的题目。

验收标准：

- 页面顶部提供岗位、公司、年份三个筛选条件。
- 筛选条件变化后列表实时更新，并显示结果数量。
- 无匹配结果时给出提示与调整建议。

### US-3.4 区分内容可信度

作为用户，我希望知道每条面经的来源与可信程度，以便判断是否值得采信。

验收标准：

- 可信度分为已核实真题、社区经验、AI 整理三类。
- 每类使用固定标识，颜色与文字保持一致。
- 页面说明各等级的含义。

## 史诗四：知识库

### US-4.1 查阅术语解释

作为游客，我希望查看岗位相关术语的解释，以便在阅读面经与 JD 时不卡在名词上。

验收标准：

- 每条术语包含名称、分类、解释与示例。
- 术语按分类组织，可连续浏览。
- 条目下方展示相关术语。

### US-4.2 筛选与搜索术语

作为游客，我希望按分类筛选或直接搜索术语，以便快速找到想查的词。

验收标准：

- 提供分类筛选入口，并展示当前分类下的条目数量。
- 提供搜索框，支持按术语名与解释内容匹配。
- 搜索无结果时给出提示。
- 输入过程中列表实时更新，输入焦点不丢失。

## 史诗五：资料库

### US-5.1 浏览学习资料

作为游客，我希望按技能分类浏览课程与教程，以便找到当前阶段需要的资源。

验收标准：

- 资料按技能分类展示。
- 每条资料包含名称、平台、难度与学习理由。
- 点击后在新窗口打开外部链接。

## 史诗六：我的计划

### US-6.1 保存学习路径

作为用户，我希望把生成的学习路径保存下来，以便之后接着推进。

验收标准：

- 成长路径页提供保存入口。
- 游客点击保存时弹出登录提示。
- 同一岗位重复保存时更新原记录，不产生重复条目。
- 保存成功后进入我的计划页。

### US-6.2 查看与继续学习

作为用户，我希望在我的计划中看到已保存的路径并继续学习，以便回到上次的进度。

验收标准：

- 列表展示岗位名称、保存日期与完成度。
- 提供继续学习入口，点击后回到对应岗位的学习路径页。
- 提供删除入口，删除后列表立即更新。
- 无保存记录时展示空状态与引导入口。

## 史诗七：账号与权限

### US-7.1 游客浏览

作为游客，我希望在不注册的情况下体验核心内容，以便先判断产品是否值得使用。

验收标准：

- 游客可以输入岗位、生成路径、查看学习路径与课程推荐。
- 游客可以查看限定数量的面经。
- 游客点击保存时触发登录提示。

### US-7.2 登录

作为游客，我希望通过一次简单操作完成登录，以便保存我的学习路径。

验收标准：

- 登录弹窗说明登录后可获得的能力。
- 登录完成后保留当前页面内容与进度。
- 导航栏显示登录后的状态。

### US-7.3 会员权益

作为用户，我希望了解会员能获得什么，以便判断是否值得订阅。

验收标准：

- 锁定区域说明会员可解锁的内容。
- 支付能力上线前，该入口仅展示说明，不产生实际扣费。

## 史诗八：内容采集与维护

### US-8.1 采集面经内容

作为内容维护者，我希望把手动整理的面经素材导入系统，以便持续丰富题库。

验收标准：

- 支持输入文本或链接形式的素材。
- 系统自动提取岗位、公司、年份、题目与答题要点。
- 自动识别重复内容并提示。
- 入库前可人工确认。
- 每条内容保留原始来源链接。

### US-8.2 内容可信度维护

作为内容维护者，我希望给内容标注可信度，以便用户判断采信程度。

验收标准：

- 可设置已核实真题、社区经验、AI 整理三种等级。
- 修改后前端展示同步更新。

## 史诗九：数据与接口

### US-9.1 前端获取数据

作为开发者，我希望前端通过统一接口获取内容，以便页面与数据解耦。

验收标准：

- 提供一次性获取全量基础数据的接口。
- 提供岗位、面经、课程、术语的独立查询接口。
- 面经、课程、术语支持筛选参数。

### US-9.2 页面直达

作为用户，我希望直接打开某个页面地址也能正常显示，以便收藏或分享。

验收标准：

- 访问非接口路径时返回前端页面。
- 刷新页面不出现 404。
